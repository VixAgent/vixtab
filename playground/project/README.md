# VixTab playground — a tiny recipe book

This repository is a sandbox created by `vixtab playground create`. Its "origin" is a local bare repository next to it, so nothing
here can reach GitHub or your real projects.

- `recipes/` — one Markdown file per recipe, listed in `recipes/INDEX.md`.
- `tickets/` — the VixTab board: five sample tickets.
- `vixtab playground check` — the test suite of this project (run by `vixtab ticket merge`).

Try it: open this folder in VS Code, click **VixTab: Orchestrate** in the status bar, and type `do all tickets on the board`.
